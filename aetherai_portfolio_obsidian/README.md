# Portfolio

A single-page personal portfolio built with plain HTML and CSS — no build step, no dependencies.

- `index.html` — the page content (replace the placeholder text with your own)
- `style.css` — layout and colours (light/dark follows your system setting)
- `GIT-GUIDE.md` — how to work on this site with Git, branches and pull requests

**View it locally:** double-click `index.html` to open it in your browser.

**Live site:** once GitHub Pages is enabled (see `GIT-GUIDE.md`, step 7), it is served at
https://odboer27.github.io/aetherai/
